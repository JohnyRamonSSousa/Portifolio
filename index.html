Minhas habilidades

Descubra as habilidades e ferramentas que domino e que me permitem criar soluções criativas e funcionais para meus clientes.

  • React.js

    Entendimento médio em hooks (useState), props e componentes, além do uso de JSON Server para simulação de APIs, React Router, tratamento de eventos e outros recursos essenciais para o desenvolvimento de aplicações React modernas e escaláveis

  • HTML

    Entendimento de HTML para estruturar páginas web de forma semântica, criando conteúdos organizados como títulos, imagens, links e formulários, com foco em acessibilidade, boas práticas de SEO e integração eficiente com CSS e JavaScript.

  • CSS

    Boas práticas com CSS com uso semântico de classes e IDs, código organizado, layouts responsivos, Flexbox, Grid, padronização visual e boas práticas para interfaces modernas, acessíveis e fáceis de manter.

  • Wordpress

    Conhecimento em WordPress e Elementor, uso de plugins para otimizar desempenho, SEO e criação de landing pages estruturadas, responsivas e eficientes.

  • PHP

    Experiência em PHP com funções, integração semântica com HTML e CSS, foco em desempenho, organização do código e conexão com bancos de dados.

  • GIT

    Controle de Git e GitHub, com domínio de branches, versionamento de código, commits, merges, pull requests e colaboração em equipe.

  • Mysql

    Entendimento de MySQL como banco de dados, com operações CRUD, consultas SQL, gerenciamento de tabelas, relacionamentos, índices e funções básicas para aplicações web.

  • Phyton

    Conhecimento básico em Python, utilizando funções e bibliotecas essenciais, com compreensão da necessidade de aprofundar estudos para ampliar habilidades e aplicar a linguagem em projetos mais complexos.
